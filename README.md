## 📥 快速获取软件

### 方式一：直接下载（推荐，最简单）

1. 点此链接 → **https://github.com/你的用户名/video-rewash-tool/releases**
2. 下载最新的 `视频去重冲洗工具.exe`
3. 双击直接运行（**不需要安装**，不需要 Python）

### 方式二：自己打包（开发者）

把本仓库 fork/下载到本地后：

```batch
pip install pyinstaller
pyinstaller --noconsole --onefile --name "视频去重冲洗工具" --add-data "ffmpeg.exe;." video_rewash.py
```

生成的 exe 在 `dist/` 目录下。

## 🖥 使用方法

```
1️⃣ 打开软件
   └── 双击 "视频去重冲洗工具.exe"

2️⃣ 选择输入文件夹
   └── 点击 "浏览..." → 选中你放视频的文件夹
   └── 默认会自动创建 ./input_videos

3️⃣ 选择输出文件夹（选填）
   └── 洗好的视频会放到这里
   └── 默认 ./output_videos

4️⃣ 点击 "🚀 一键开始冲洗"
   └── 程序自动工作，实时显示进度

5️⃣ 等待完成
   └── 处理完的输出视频在 output_videos 里
```

## ❓ 常见问题

**Q: 需要安装 FFmpeg 吗？**
A: 不需要！exe 自带 ffmpeg 核心组件。

**Q: 需要 NVIDIA 显卡吗？**
A: 不需要。有 N 卡自动加速，没有自动用 CPU 编码。

**Q: 支持什么格式？**
A: mp4, avi, mov, mkv, flv, wmv, webm, ts, m4v。

**Q: 视频会被压缩变模糊吗？**
A: 变化极小（缩放 1.02~1.05x，CRF 23 无损级画质），肉眼几乎看不出来。
